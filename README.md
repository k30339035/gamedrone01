# 🚁 3D Drone Sky Writer - 드론 스카이 라이터

하늘에 글씨를 그리는 멋진 3D 드론 게임입니다!

## ✨ 주요 기능

- 🎮 **3D 그래픽**: Three.js를 사용한 실시간 PBR 렌더링
- ✍️ **다국어 지원**: 한글, 영어, 숫자 모두 지원
- 🚁 **프리미엄 드론 모델**: 영화 촬영용 수준의 초현실적 3D 드론
- 🔊 **실시간 사운드**: Web Audio API로 생성된 실제 드론 프로펠러 소리
  - 다중 오실레이터 저주파 엔진음
  - 핑크 노이즈 프로펠러 소용돌이 소리
  - 속도에 따른 동적 주파수/볼륨 변화
- ✨ **파티클 효과**: 드론이 움직일 때마다 생성되는 화려한 파티클
- 🌈 **트레일 효과**: 드론이 지나간 경로를 실시간으로 표시
- ⚡ **속도 조절**: 애니메이션 속도를 자유롭게 조절
- 📊 **실시간 진행률**: 드론 개수와 진행률을 실시간 표시
- 🌤️ **아름다운 환경**: 구름, 조명, 그림자가 있는 현실적인 하늘
- 🎬 **영화같은 카메라**: 자동 회전하는 시네마틱 카메라

## 🎯 프리미엄 드론 디자인 (영화 촬영용 수준!)

각 드론은 **DJI Inspire/Phantom 프리미엄급** 초현실적 3D 모델:

### 본체 & 구조
- **에어로다이나믹 바디**: 곡선형 유선형 디자인 (상/하 셸 구조)
- **중앙 티타늄 링**: CNC 가공 금속 허브
- **사이언 LED 링**: 상단 청록색 상태 표시등 (발광)
- **GPS 돔**: 투명 커버의 GPS 모듈
- **LiPo 배터리**: 블루 고성능 배터리 팩 (XT60 커넥터)
- **환기 슬롯**: 8방향 냉각 슬롯 (프리미엄 디테일)

### 암 & 모터 시스템 (각 4개)
- **카본 파이버 암**: 테이퍼 3단 구조 (끝으로 갈수록 얇아짐)
- **화이트 레이싱 스트라이프**: 스포츠카 스타일 액센트
- **브러시리스 모터**:
  - 모터 베이스 (매트 블랙)
  - 8개 티타늄 냉각 핀
  - 모터 벨 (티타늄 마감)
  - 구리 코일 디테일 (내부 가시)
  - 정밀 티타늄 샤프트
- **3날 에어포일 프로펠러**: ExtrudeGeometry 곡선 블레이드
- **CNC 알루미늄 허브**: 6각 디자인
- **빨간 아노다이징 너트**: 중앙 고정 나사
- **항공급 LED**: 전방(빨강) 후방(초록) 항법등
- **블루 파워 LED**: 모터 작동 표시등

### 카메라 시스템
- **3축 프로 짐벌**: 티타늄 볼 조인트 + 듀얼 암
- **프리미엄 카메라 하우징**: 콤팩트 박스 디자인
- **대형 센서 렌즈**: Ø18mm 렌즈 어셈블리
- **멀티 코팅 글래스**: 반사 파란 렌즈 (발광)
- **렌즈 후드**: 빛 차단 후드
- **녹화 LED**: 빨간 상태 표시등

### 랜딩 기어
- **카본 파이버 스트럿**: 경량 다리 구조
- **쇼크 업소버**: 티타늄 완충 장치
- **고그립 풋 패드**: 편평 러버 패드

### 통신 시스템
- **듀얼 다이버시티 안테나**: 좌/우 2개 안테나
- **신호 팁**: 빨간 안테나 끝단

### 재질 (PBR 사실적)
- **카본 파이버**: Metalness 0.95, Roughness 0.2
- **티타늄**: Metalness 0.98, Roughness 0.12
- **매트 플라스틱**: Metalness 0.1, Roughness 0.8
- **광택 플라스틱**: Metalness 0.4, Roughness 0.3
- **빨간 액센트**: Emissive 효과 포함

## 🚀 사용 방법

1. **index.html** 파일을 웹 브라우저로 엽니다
2. 입력창에 원하는 글자나 숫자를 입력합니다
   - 한글: ㄱ, ㄴ, ㄷ, ㄹ, ㅁ, ㅂ, ㅅ, ㅇ, ㅈ, ㅊ, ㅋ, ㅌ, ㅍ, ㅎ
   - 영어: A-Z (대소문자 모두 지원)
   - 숫자: 0-9
3. **"드론 출발!"** 버튼을 클릭합니다
4. 드론들이 순차적으로 하늘에 글씨를 그립니다!

## 🎮 조작 방법

- **드론 출발**: 입력한 글자를 드론으로 그리기 시작
- **초기화**: 모든 드론과 트레일을 제거하고 처음부터 시작
- **빠르게**: 애니메이션 속도를 1.5배 증가
- **느리게**: 애니메이션 속도를 1.5배 감소

## 🎨 시각 효과

- **카메라 회전**: 카메라가 자동으로 회전하여 다양한 각도에서 글씨를 볼 수 있습니다
- **프로펠러 회전**: 모든 드론의 프로펠러가 실시간으로 회전합니다
- **드론 흔들림**: 실제 드론처럼 미세하게 흔들립니다
- **LED 조명**: 각 드론에 빨강/초록 LED가 번갈아가며 빛납니다
- **파티클**: 드론이 움직일 때 화려한 파티클이 생성됩니다
- **트레일**: 각 드론이 지나간 경로가 색깔별로 표시됩니다

## 💡 예제 입력

- **한글**: ㅎㅇ, ㄱㅅ, ㅁㄴㅂ
- **영어**: HELLO, LOVE, SKY
- **숫자**: 2025, 123, 789
- **혼합**: A1B2, ㅎㅇ123

## 🎬 작동 원리

1. 입력된 텍스트를 분석하여 각 문자의 경로를 생성합니다
2. 각 경로 세그먼트마다 드론을 생성합니다
3. 드론들이 순차적으로 활성화되어 경로를 따라 움직입니다
4. 움직임에 따라 파티클과 트레일이 생성됩니다
5. 카메라가 회전하며 전체 글씨를 다양한 각도에서 보여줍니다

## 🌟 특별 기능

- **스태거 애니메이션**: 드론들이 순차적으로 출발하여 글씨가 한 획씩 그려집니다
- **다중 조명**: 태양광, 포인트 라이트, LED 조명이 조합되어 입체감을 만듭니다
- **그림자**: 드론과 객체들이 실시간 그림자를 생성합니다
- **안개 효과**: 거리감을 주는 안개 효과
- **구름**: 배경에 떠다니는 3D 구름
